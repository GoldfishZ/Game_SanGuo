三国武将卡牌游戏 — Windows 发行版

启动：
1. 请先完整解压 ZIP 文件。
2. 双击 Game_SanGuo.exe。
3. 程序会自动打开默认浏览器。
4. 保留控制台窗口；结束游戏时回到控制台按回车。

玩法：
- PvE：可选择简单、普通、困难三档 AI；三档均包含独立的选将、布阵和战斗模型。
- PvP：支持同一台电脑上的本地双人依次操作。

注意：
- 不要把 Game_SanGuo.exe 单独移出本目录，旁边的 _internal 文件夹是运行所需内容。
- 游戏只监听本机回环地址，不会向局域网开放服务。
- 这是未签名的个人发行程序，Windows SmartScreen 可能要求确认来源。
